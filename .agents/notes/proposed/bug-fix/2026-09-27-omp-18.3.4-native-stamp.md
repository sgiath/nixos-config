# Agent Note: omp 18.3.4 native addon lacks its version stamp

Status: proposed

## Problem

On 2026-09-27, an uncommitted `oh-my-pi` input bump from v18.3.2 to v18.3.4 in `flake.nix` failed while building `nixosConfigurations.ceres`. Both `omp-18.3.4` derivations failed at the upstream `bun --cwd=../natives run gen:native` step:

```text
Native addon .../packages/natives/native/pi_natives.linux-x64-baseline.node does not carry the
@oh-my-pi/pi-natives@18.3.4 version stamp `PI_NATIVES_VERSION_STAMP:18.3.4`.
```

This blocked the Ceres Home Manager generation (and `system-failure-watcher`). The failure is in oh-my-pi's Nix packaging, not this repository's ComfyUI changes. `flake.nix` currently pins v18.3.2.

## Proposal

Before bumping `oh-my-pi` to v18.3.4, use an upstream release or packaging fix that stamps the native addon during the Nix build. Keep the working v18.3.2 pin until that is available.

## Acceptance criteria

- The bumped `omp` derivations build with the matching native addon version stamp.
- `nixosConfigurations.ceres` builds its Home Manager generation, including `system-failure-watcher`, with the bumped input.
