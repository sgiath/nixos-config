# Agent Notes

Follow [`README.md`](README.md) for lifecycle, classification, format, supersession, and archive rules.

Search the active tree before creating a note. Update an existing owner when the decision is unchanged; create and cross-link a new note when the decision changes.

Moving a note to `implemented/` is part of the change that implements it: do it in the same pull request as the code, not after merge (see [Lifecycle moves ship with the code](README.md#lifecycle-moves-ship-with-the-code)).

Files under `archived/` are frozen historical snapshots, never current authority. Do not edit them after migration.
